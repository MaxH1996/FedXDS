Implementation of FedXDS. We provide code to run a sample experiment with CIFAR10.


Requirements:
```
torch                     2.3.0
flwr                      1.10.0                   
flwr-datasets             0.3.0               
zennit                    0.5.1
zennit-crp                0.6.0
```
Run experiment with:

```
bash run.sh
```
